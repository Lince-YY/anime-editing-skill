# 跨番动态合成：让新剧情在画面中发生

适用：需要人物/道具处于共同空间并发生接触、攻击、交接等事件。以下是有来源的局部合成方法和推导（文档核验日期：2026-10-06）。2026-10-09 的无惨样板最终以新绘动作路线获用户接受；下述局部替换方法没有因此被验证为适用于该持物镜头。

## 先检查最难事件的素材

把故事的关键动词变成画面要求，然后反查原作；不要先填满配音时间轴。

| 要成立的事件 | 必须找到或控制的画面 | 不足以证明事件的素材 |
|---|---|---|
| 拿着/呈出道具 | 相容的手势、接触位置、物件视角、朝向对象、运动与遮挡 | 人物说话后切一张道具特写 |
| 交接 | 持有者改变、双方手部或可辨接触、交接前后位置连续 | 两个人分别伸手但物件归属不明 |
| 攻击命中 | 出手方向、目标位置、作用点或可辨目标变化、反应 | 两段各自好看的招式 |
| 同场对话 | 共同环境线索、相容轴线/视线、开口停口和对应反应 | 新字幕与任意张嘴镜头 |

每个必要元素标“已找到”“需合成”“缺失”，依据原片实际帧和上下文。资料里写“使用面具”不等于有适合抠出的完整面具；某几个片段不可用，也不等于全作都没有。记录已检索范围，继续有目标地找视角/姿态。

持物先判断原手势能否包住所选物体：前掌、指缝、拇指、支撑点和对象尺度是否合理。手势、透视严重不匹配时换镜头。缩放、换背景和整人抠像都不能凭空制造抓握。平面透视变换可近似小转角；面具等有厚度物体大转面时，必须有对应原作视角或调整镜头设计，不能把一张正面图拉扁充当侧面。[平面映射原理](https://docs.opencv.org/4.x/d9/dab/tutorial_homography.html)

“原版HD素材”检查版本、原语言、实际画幅和源片质量；额外记录物件裁切后的尺寸、放大倍数及观感。不要通过输出分辨率声称裁切细节不存在损失。

当原手势或必要动作根本缺失，或接触漂移反复出现且跟踪修正不再增加控制力时，比较换镜头、改动作与获准的新绘路线，见[已验证样板](validated-reanimation.md)。先画正确握姿再生成连续动作，是另一条路线；不要把它的成功记到局部替换名下。

## 分层与素材修补

持物的典型从后到前层级是：**背景/修补底片 → 人物与后手掌 → 道具 → 前手指/衣袖等遮挡层 → 必要局部光色处理**。这是一种工程方案，具体前后关系由原帧决定，不能用整只手覆盖物件代替逐部位遮挡。

- 道具Alpha与手指遮挡matte分开保存。先挑清晰参考帧，用少量曲线点贴轮廓；关节、头发、手指等独立变化部位分开做蒙版，连接区适度重叠避免裂缝，再在动作变化处修关键帧。[Reisir的动漫蒙版方法](https://amv.tools/after-effects/masking)
- 颜色分离明显时可用通道/色阶辅助取Alpha，先用粗蒙版限制区域，再检查细线和相近颜色；不能把单一发色案例推广到复杂背景。自动Roto/分割仅给初始matte，所有实际使用帧仍要检查。[Tfrog的动漫抠像正文](https://amvtutorial.com/tutorials/anime-rotoscope)
- 原道具露边、手指移开后的底片或面具被挡部位，优先从同一原作其他已存在帧取兼容像素，按时间、位置和视角配准；保存取样源帧与变换。AE Clone Stamp支持指定源层、源时间及位置，可在透明层做修补。它不能提供从未出现的结构。[Adobe源像素复制](https://helpx.adobe.com/after-effects/desktop/drawing-painting-and-paths/paint-tools-and-paint-strokes/paint-tools-brush-clone-stamp.html)
- 无可用原帧时，换镜头/缩小运动范围，或明确列出需要补画的部分。生成式填充、AI重绘、3D重建、新口型动画都不是原作现成像素；只有本次范围允许才进入相应路线。普通调色、裁切、几何变换并不自动违反“用原版素材”；只有用户另要求像素不变时才排除。

## 运动跟踪与前景遮挡分别完成

先在参考帧配准物件的比例、角度、握持点，再施加运动；跟踪区域的轮廓不是物件边界。

| 镜头条件 | 首选控制 | 检查重点 |
|---|---|---|
| 短段、小幅平移/旋转/缩放 | 点跟踪或手工Transform关键帧 | 手与物件的接触点是否滑动 |
| 稳定表面有真实透视变化 | 同平面跟踪、Corner Pin/Plane Track | 四角和内部形状是否随原动作合理变化 |
| 手指弯曲/相互遮挡 | 独立蒙版形状关键帧，可绑定整体轨迹 | 指尖/指缝和物件前后关系 |
| 物体大幅转面、原姿态缺失 | 换原作角度/动作，或调整镜头 | 跟踪器不能补出未见体积 |

手是非刚性的；优先跟踪稳定的原道具或掌部区域，不强行把独立运动的手指当同一个平面。遮挡跟踪目标时，可排除遮挡区域、分段或手动修正。用于排除跟踪污染的mask与最终前景手指matte用途不同。

从清晰参考帧向两端处理；在作画换帧、握姿变化和遮挡边界检查，再检查关键帧之间。原动画有保持帧和跳变时，关键帧插值应匹配源运动，不能默认平滑插值让道具自己漂走；切镜处重新建立跟踪。

## 选一条真实可用的工具路线

优先现有安装/许可，首次只跑一个关键镜头；不为了工具齐全同时装三套。软件版本、启动/许可、可调用入口和镜头效果分别核验。以下步骤是文档路线，自动化和质量仍须在本机验证。

### AE + 自带Mocha AE：已有许可时

对原镜头应用Mocha AE，跟踪稳定区域；在AE侧Create Track Data，按运动选Transform或Corner Pin，再Apply Export到已配准物件层。另复制原镜头，独立抠出前手指放在物件上方。Mocha的Create AE Masks不带其边缘羽化，Apply Matte保留，导入后核对Alpha。漂移时用AdjustTrack/分段与手动关键帧修正。[Adobe跟踪文档](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/track-motion/tracking-stabilizing-motion-cs5.html)

AE脚本能组织工程及关键帧，aerender能导出；不能据此声称Mocha分析和手指Roto已无人值守。AE需要有效许可，自带Mocha AE不等于付费Mocha Pro。

### Resolve Fusion：零付费手工样板的候选

原镜头进PlanarTracker，选清晰参考帧分析后Create Planar Transform。物件RGBA先配准，再经过PlanarTransform接Merge前景；原镜头接背景。再用第二个Merge，把原镜头中由Polygon/B-spline选出的前手指盖回物件上方。保持参考帧坐标一致，避免重复施加变换；Polygon形状按指节动作手修。

官方Resolve20 VFX训练书的课程可用免费版，包含平面跟踪和动画蒙版；这条方法不需要Magic Mask。不同安装版本的节点、解码格式与许可须现场核验；旧Fusion脚本手册不能证明当前免费Resolve允许所有外部自动化。[官方训练书，第4–5课](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-20-Fusion-Visual-Effects.pdf)

### Blender：零付费、需要脚本入口时的候选

Movie Clip Editor里有至少四个同平面有效特征点时，可Create Plane Track。Compositor用Plane Track Deform变换物件，再Alpha Over回原镜头；前手指另做Mask、用原镜头像素与Set Alpha形成前景，再Alpha Over。Mask可绑定点/平面轨迹，但指节变形仍需形状关键帧。没有稳定同平面点时用短段手工变换，不能为了四点要求强跟非刚性手。[平面跟踪](https://docs.blender.org/manual/en/4.4/movie_clip/tracking/clip/editing/track.html)、[Plane Track Deform](https://docs.blender.org/manual/en/4.4/compositing/types/tracking/plane_track_deform.html)、[Mask绑定](https://docs.blender.org/manual/en/4.5/movie_clip/masking/sidebar.html)

CLI/Python存在不等于跟踪操作可无界面直接跑；先验证选定版本的操作上下文、mask动画和导出，再扩展自动化。不先自建一整套合成框架。

### 自动分割的边界

Roto Brush、SAM等可辅助生成matte，不能决定故事动作、补缺失视角或保证细手指。先验证模型/插件对该镜头是否有帮助，再考虑批量。官方SAM3/3.1视频路线截至本次核验要求CUDA环境，不能作为Apple Silicon机器开箱即用的默认方案；需要验证的移植版另记条件。[官方SAM3仓库](https://github.com/facebookresearch/sam3)

## 融合、声音与验收

检查Alpha解释方式与边缘白/黑边，再匹配线条锐度、曝光、光源方向和局部接触阴影。参数按原片定，不统一加宽羽化、实拍式运动模糊或轮廓光。原来烘焙的阴影冲突严重时优先换素材。[CaptainX的选材与调色案例](https://www.bilibili.com/opus/78157645896715991)

先用一个真实动态段解决最难事件；静帧只用于确认摆位和图层关系。检查顺序：去解释性字幕/新对白看事件 → 原速连续看运动/接触/遮挡 → 查最大位移、转角与换帧细节 → 恢复声音检查开口停口、对象反应、音效时机。对关键动作的连续观看未完成时保留“待验证”，不能用联系表、ASR、文件可解码代替。

有以下问题就停在该镜头修正或换材，不扩大完整初剪：姿态不可能握住物件；物件与手漂移；遮挡顺序错；正面图被拉成假侧面；原速明显静止贴图；主要事件仍只能靠对白解释。找不到素材时说明已查范围与准确缺口，不把困难包装成已完成能力。

通过后保存原素材映射、道具Alpha、遮挡matte、轨迹/手修关键帧、可编辑工程和观看覆盖，见[记录要求](pilot-schema.md)。把一次镜头通过标成该镜头通过，不能升级为任意番剧全自动制作。
